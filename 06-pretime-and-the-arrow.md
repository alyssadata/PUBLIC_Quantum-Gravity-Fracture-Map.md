## Clock-time is too late

Clock-time already assumes a stable frame.

It assumes something can be measured.

So clock-time cannot be the first form of time if the stage itself has not been earned.

Clock-time is not the beginning.

Clock-time is a later stabilization.

## Pre-time

Pre-time is not time as measured by a clock.

Pre-time means ordered depth before duration.

It means there is a directional structure, but not yet a measurable interval.

It can hold:

before / after shape  
prior / later structure  
nested order  
sequence without seconds  
arrow without ruler  

## The arrow

The arrow comes from containment asymmetry.

A later fold may contain an earlier fold.

The earlier fold does not contain the later fold.

That asymmetry gives direction.

Not because a clock is ticking.

Not because a particle moved.

Not because space already exists.

But because the structure is not reversible in the same way.

The contained and the container are not equivalent.

## Why containment matters

If Fold 2 contains Fold 1, then Fold 1 is structurally prior.

If Fold 1 does not contain Fold 2, then Fold 2 is structurally later.

This gives an order.

That order may be the earliest candidate for time’s arrow.

Not time yet.

But time’s precondition.

## Sequence without duration

Sequence says:

this comes before that.

Duration says:

this lasted this long.

Those are not the same.

At this stage, the model may have sequence.

It does not yet have duration.

So the current restraint is:

**Do not confuse order with measure.**
